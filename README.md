# Calculatrice en Assembleur 

Programme de calculatrice développé en langage assembleur dans le cadre
du cours INF2171 (Organisation des ordinateurs et assembleur) à l'UQAM.

## Description

Programme bas niveau implémentant les opérations arithmétiques de base
en langage assembleur x86.

## Fonctionnalités

- Addition
- Soustraction
- Multiplication
- Division

## Technologies

- Langage Assembleur (x86)
- Linux

## Cours

INF2171 — Organisation des ordinateurs et assembleur, UQAM
